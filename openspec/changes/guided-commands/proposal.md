# Proposal

## Why

Текущий CLI REPL принимает свободный текст и отправляет его агенту (LLM) — это непредсказуемо, расходует токены на разбор интента и не даёт контроля над форматом ввода. Пользователю нужны предсказуемые guided-команды для типовых операций с почтой: `/find` (поиск), `/analyze` (поиск+анализ), `/download` (поиск+скачивание вложений), `/send` (отправка с подтверждением). Сбор критериев должен быть детерминированным CLI-мастером (без LLM на этапе ввода), LLM привлекается только там, где нужна интеллект — анализ содержимого письма в `/analyze`.

## What Changes

- **MODIFIED** capability `transport/cli`:
  - REPL принимает только slash-команды; свободный текст больше не отправляется агенту.
  - Состав slash-команд: `/quit` (выход), `/stats` (отчёт сессии — из observability), `/find`, `/analyze`, `/download`, `/send`. Убираются: `/help`, `/clear`, `/reset`.
  - Новые guided-команды со структурированным мастером сбора критериев.
- Новые требования к поведению:
  - **Мастер сбора критериев**: сбор в формате `тема - <текст>`, `дата - <YYYY-MM-DD>`, `отправитель - <email>`; валидация формата/даты/email; при неверном вводе — повторный запрос.
  - **Выбор почты**: если настроено несколько аккаунтов — команда запрашивает выбор почты (логин) после сбора критериев.
  - **`/find`**: поиск писем по критериям, вывод списка найденных (до 50).
  - **`/analyze`**: поиск → если несколько совпадений, показ первых 5 + запрос уточнения (UID) → fetch письма → анализ через субагента-анализатора (LLM) → вывод саммари.
  - **`/download`**: поиск → если несколько совпадений, показ первых 5 + запрос уточнения (UID) → fetch → скачивание вложений в системную папку загрузок (`~/Загрузки`).
  - **`/send`**: сбор `тема - …`, `текст - …`, `получатель - <email>` + выбор почты → подготовка черновика → вывод черновика пользователю → подтверждение да/нет → отправка или отмена.

## Capabilities

### New Capabilities
(нет — все изменения в существующей capability `transport/cli`)

### Modified Capabilities
- `transport/cli`: REPL принимает только slash-команды; состав команд изменён (убраны `/help`/`/clear`/`/reset`, добавлены guided-команды `/find`/`/analyze`/`/download`/`/send`); добавлены требования к мастеру сбора критериев, выбору почты и поведению каждой guided-команды.

## Impact

- **Код:** `src/transport/cli/repl.ts` (убрать свободный текст, обновить маршрутизацию команд), новый модуль мастера ввода (например `src/transport/cli/prompts.ts`), обработчики команд (`src/transport/cli/commands/`), интеграция с реестром тулов (`mail.search`/`mail.fetch`/`mail.downloadAttachments`/`mail.send`) и субагентом-анализатором для `/analyze`.
- **API:** `CliRepl` меняет поведение (только slash-команды); существующие тесты REPL (`cli-repl.test.ts`, `cli-repl-progress.test.ts`, `cli-repl-integration.test.ts`, E2E `cli-e2e-*.test.ts`) потребуют обновления — свободный текст больше не валиден, старые команды убраны.
- **Зависимости:** без новых runtime-зависимостей (мастер ввода — readline + парсинг).
- **Спека:** `transport/cli` MODIFIED — требования «Slash-команды» и «REPL-цикл терминала» изменены, добавлены новые требования (мастер, выбор почты, 4 команды).
- **Совместимость:** `/help`, `/clear`, `/reset` убираются (breaking для пользователей CLI, но CLI — внутренний транспорт, внешних потребителей нет).
