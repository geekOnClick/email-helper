# Spec Delta

## MODIFIED Requirements

### Requirement: Повтор операции поиска при обрыве соединения

При обрыве IMAP-соединения во время поиска (ошибки вида `Connection not available` и иные сетевые сбои, включая `подключение не установлено` при `client === null` после неудачного/невыполненного переподключения) система SHALL переподключить IMAP-сессию и повторить поиск, до `MAIL_OP_MAX_RETRIES` повторов (по умолчанию 2). Переподключение SHALL использовать существующий lifecycle провайдера (закрытие старой сессии и новое подключение) без изменения учётных данных аккаунта. Если все повторные попытки исчерпаны и соединение не восстановлено — система SHALL вернуть ошибку, маскирующую секреты.

#### Scenario: Обрыв соединения — повтор с переподключением

- **WHEN** во время поиска IMAP-соединение обрывается (`Connection not available`)
- **THEN** система переподключает сессию и повторяет поиск; при успехе на повторе возвращает нормальный результат

#### Scenario: Успех на первой попытке — без повторов

- **WHEN** поиск завершается успешно без обрыва соединения
- **THEN** система не выполняет переподключение и лишние повторы, возвращает результат сразу

#### Scenario: Исчерпание повторов — ошибка

- **WHEN** обрыв соединения повторяется чаще `MAIL_OP_MAX_RETRIES`
- **THEN** система возвращает ошибку, сообщающую о недоступности соединения, с замаскированными секретами

#### Scenario: Секреты маскируются в ошибке повтора

- **WHEN** повтор с переподключением завершается ошибкой аутентификации или соединения
- **THEN** сообщение об ошибке не содержит пароля приложения, логина в открытом виде или access token

#### Scenario: «Подключение не установлено» — повтор с переподключением

- **WHEN** операция поиска падает с ошибкой `подключение не установлено` (client обнулён после неудачного/невыполненного переподключения), а попытки ещё остались
- **THEN** система тратит попытку на переподключение и повторяет поиск; при успехе возвращает нормальный результат

#### Scenario: Дефолт потолка повторов — 2

- **WHEN** конфигурация не задаёт `MAIL_OP_MAX_RETRIES`
- **THEN** система использует значение по умолчанию 2 (итого до 3 попыток на операцию: первичная + 2 повтора)
