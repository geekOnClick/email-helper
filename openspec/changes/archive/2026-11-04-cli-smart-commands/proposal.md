# Proposal

## Why

Текущий набор CLI-команд `/find`, `/find-all`, `/download`, `/send` опирается на серверный IMAP SEARCH по теме/отправителю (ненадёжный на Яндексе) и отправляет письма, требуя готовый текст от пользователя. Команды дублируют MCP-тулы и не используют LLM для продуктивной работы: нет批量-анализа писем, нет анализа вложений, нет генерации тела письма по произвольному промпту. Нужно заменить их на «умные» команды, оставив MCP-путь (тулы `mail.*`) без изменений.

## What Changes

- **BREAKING**: убрана команда `/find` (поиск писем). Логика поиска переезжает в shared-утилиту `collectAllMessages`, используемую новой `/analyze-many`.
- **BREAKING**: убрана команда `/find-all` (поиск всех писем таблицей). Мастер критериев `promptFindAllCriteria` сохраняется и переиспользуется `/analyze-many`.
- **BREAKING**: убрана команда `/download` (скачивание вложений).
- **BREAKING**: убрана команда `/send` (отправка с ручным вводом текста).
- Добавлена команда `/analyze-many`:批量-поиск писем по критериям `/find-all` (тема/отправитель/диапазон дат, локальная фильтрация) → фетч тел через `mail.fetch` → один вызов субагента-анализатора, формирующий краткое саммари каждого письма + общий смысл всех писем (если он есть). Потолок `ANALYZE_MANY_MAX_EMAILS` (дефолт 10), при превышении — усечение с предупреждением.
- Добавлена команда `/analyze-attachments`: поиск → выбор письма (1 → сразу, >1 → UID) → скачивание вложений во временную папку → извлечение текста (txt/csv/json/html/eml напрямую; PDF/DOCX/XLSX через `pdf-parse`/`mammoth`/`xlsx`; изображения и бинарные форматы — пропуск с пометкой) → анализ субагентом → саммари каждого вложения → удаление временных файлов всегда.
- Добавлена команда `/smart-send`: пользователь вводит тему, получателя и произвольный промпт → прямой one-shot вызов `RouterAiClient` (роль `helper`) генерирует тело письма (plain text) → предпросмотр → подтверждение «отправить да/нет» или промпт-правка (модель правит только тело, тема/получатель фиксированы) → при подтверждении отправка через `mail.send`. Цикл правки повторяется до подтверждения/отмены.
- **Не меняется**: тулы `mail.*` (`mail.search`, `mail.fetch`, `mail.downloadAttachments`, `mail.send` и др.), MCP-путь оркестратора, спеки `mail/*`.

## Capabilities

### New Capabilities

_(нет — все новые команды принадлежат существующей capability `transport/cli`.)_

### Modified Capabilities

- `transport/cli`: убираются требования под `/find`, `/find-all`, `/download`, `/send`; добавляются требования для `/analyze-many`, `/analyze-attachments`, `/smart-send`; обновляется требование «Slash-команды guided-режима» (новый список команд).

## Impact

- **Исходный код CLI-слоя**: удаление `commands/find.ts`, `commands/find-all.ts`, `commands/download.ts`, `commands/send.ts`; перенос `collectAllMessages` в новый `commands/search-aggregator.ts`; новые `commands/analyze-many.ts`, `commands/analyze-attachments.ts`, `commands/smart-send.ts`, `commands/attachment-text.ts`; обновление `commands/index.ts`, `repl.ts`, `prompts.ts`, `format.ts`, `bootstrap.ts`, `index.ts`.
- **Зависимости**: добавляются `pdf-parse`, `mammoth`, `xlsx` для извлечения текста вложений в `/analyze-attachments`.
- **Конфигурация**: новое env-значение `ANALYZE_MANY_MAX_EMAILS` (дефолт 10) + поле в `Config`/`bootstrap`/`CliRepl`.
- **Тесты**: удаление/адаптация тестов убранных команд; новые тесты для трёх новых команд + утилиты извлечения текста + обновлённые маршруты REPL.
- **MCP-путь и тулы `mail.*`**: не затрагиваются.
