# Spec Delta

## MODIFIED Requirements

### Requirement: Команда /find

Команда `/find` SHALL запустить мастер сбора критериев, выполнить поиск писем через тул
`mail.search` и вывести список найденных писем: для каждого — тема, отправитель, дата, UID.
Если ничего не найдено — SHALL сообщить об отсутствии результатов.

Поиск SHALL выполняться с локальной фильтрацией темы и отправителя: на серверный `mail.search`
SHALL передаваться **только** диапазон дат (`since`/`before`), а `subject`/`from` SHALL
фильтроваться локально после фетча метаданных. Это гарантирует, что письма, которые серверный
IMAP SEARCH по теме/отправителю пропускает (ненадёжный кириллический `SUBJECT`-литерал или
адрес `FROM`), всё равно находятся.

- Явная `дата` из мастера SHALL преобразовываться в один день включительно: `since` = полночь
  указанного дня, `before` = полночь следующего дня.
- Без явной даты система SHALL применять bounded окно `since` = `now − MAIL_SEARCH_FALLBACK_DAYS`
  (по умолчанию 180), чтобы не фетчить весь ящик.
- При достижении лимита пагинации система SHALL вывести предупреждение, что показаны не все
  найденные письма.

#### Scenario: Найдены письма — вывод списка

- **WHEN** критериям соответствуют письма
- **THEN** система выводит список: тема, отправитель, дата, UID для каждого найденного письма

#### Scenario: Тема и отправитель фильтруются локально

- **WHEN** пользователь вводит `тема - Успешная оплата` и `отправитель - no-reply@igm.gg` без даты, и письмо с такими темой/отправителем существует в INBOX
- **THEN** система передаёт на сервер только bounded `since` (без `subject`/`from`), фетчит письма окна, фильтрует локально по теме и отправителю и находит целевое письмо

#### Scenario: Явная дата — один день включительно

- **WHEN** пользователь вводит `дата - 2026-11-03`
- **THEN** система передаёт на сервер `since` = полночь 2026-11-03 и `before` = полночь 2026-11-04 (только письма этого дня)

#### Scenario: Ничего не найдено

- **WHEN** критериям не соответствует ни одно письмо
- **THEN** система выводит сообщение об отсутствии результатов

#### Scenario: Достигнут лимит пагинации

- **WHEN** число писем в окне поиска превышает потолок пагинации
- **THEN** система выводит найденные письма и предупреждение, что показаны не все
