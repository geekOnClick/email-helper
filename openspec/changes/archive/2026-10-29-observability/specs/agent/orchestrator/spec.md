# Spec Delta

## MODIFIED Requirements

### Requirement: Цикл tool-calling

Система SHALL выполнять итеративный цикл: отправить запрос к LLM с доступными тулами, исполнить возвращённые вызовы тулов и передать их результаты обратно в LLM, и SHALL завершать цикл, когда модель отвечает без вызовов тулов. При подключённом наблюдателе прогресса система SHALL испускать событие с номером итерации, вызовом тулa (имя, аргументы) и его результатом или ошибкой по каждому исполненному тулу, не меняя видимый результат цикла при отсутствии наблюдателя. Система SHALL агрегировать использование токенов LLM по всем итерациям цикла в пределах одного прогона и SHALL возвращать агрегированное использование в результате цикла.

#### Scenario: Финальный текстовый ответ

- **WHEN** модель отвечает текстом без `tool_calls`
- **THEN** цикл завершается и возвращает текст ответа

#### Scenario: Вызов тулa и финал

- **WHEN** на первой итерации модель вызывает тул, а на второй отвечает текстом
- **THEN** цикл исполняет тул, передаёт результат модели и завершается финальным ответом

#### Scenario: Несколько вызовов подряд

- **WHEN** модель возвращает несколько вызовов тулов в одном ответе
- **THEN** система исполняет их все и передаёт все результаты в следующую итерацию

#### Scenario: Событие прогресса по вызову тулa

- **WHEN** к циклу подключён наблюдатель прогресса и модель вызывает тул
- **THEN** система испускает событие с именем тулa, его аргументами и результатом (или ошибкой), не меняя возвращаемый результат цикла

#### Scenario: Без наблюдателя поведение не меняется

- **WHEN** к циклу не подключён наблюдатель прогресса
- **THEN** цикл выполняется идентично: не испускает событий и возвращает тот же результат

#### Scenario: Токены агрегируются по итерациям прогона

- **WHEN** прогон цикла содержит несколько итераций, каждая из которых вернула использование токенов
- **THEN** результат цикла содержит сумму токенов промпта, генерации и общих по всем итерациям прогона, а не только последней итерации
