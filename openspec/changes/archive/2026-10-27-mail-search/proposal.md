# Proposal

## Why

Change `mail-connect` (Phase 1) завершил подключение к ящику и список папок. Следующий шаг Фазы 1 по `PLAN.md` — поиск писем: без `mail.search` невозможны ни чтение, ни скачивание вложений, ни анализ. Помощник должен находить письма по теме, отправителю, дате, папке и направлению (входящие/исходящие), не выгружая весь ящик.

## What Changes

- Новый тул `mail.search` — поиск писем в ящике по критериям: тема, отправитель, получатель, дата (since/before), флаги (unseen и др.), папка.
- Поддержка направления (входящие/исходящие) через выбор папки (`\Inbox` / `\Sent`) — поиск идёт в указанной папке.
- Результат — список метаданных писем (UID, тема, отправитель, дата, флаги), без тел; тело — отдельный тул `mail.fetch` (следующий change).
- Доменные типы `EmailMessage` (метаданные), `SearchCriteria`, `SearchResult` в `src/types/`.
- Расширение `MailProvider`/`AbstractImapProvider`: метод `search(criteria): Promise<EmailMessage[]>`, открытие папки перед поиском.
- Возможность ограничения количества результатов (limit), постраничный доступ через диапазон UID/seq.
- Юнит-тесты с моком IMAP; интеграционный gated-тест против Яндекс-ящика (отправить себе тестовое письмо вручную, найти по теме).
- Обновление `skills/helper.md` — `mail.search` в списке доступных тулов.

## Capabilities

### New Capabilities

- `mail/search`: поиск писем в почтовом ящике по критериям (тема, отправитель, получатель, дата, флаги) с указанием папки и направления, возврат метаданных без тел.

### Modified Capabilities

Нет — поиск материалов не меняет требования `mail/connection` (подключение и список папок остаются как есть); поиск — отдельная capability.

## Impact

- **Новый код:** `src/types/email.ts` (`EmailMessage`, `SearchCriteria`, `SearchResult`); расширение `MailProvider`/`AbstractImapProvider` (`search`, открытие папки); `src/tools/mail/mail-search.tool.ts`; регистрация тулa.
- **Без новых зависимостей** — imapflow уже установлен, `search`/`fetchAll`/`mailboxOpen` в его API.
- **Расширение `ImapClient`** (мока) методами `mailboxOpen`, `search`, `fetchAll`.
- **Внешние системы:** `imap.yandex.ru:993`, `outlook.office365.com:993` (через активную сессию из `mail.connect`).
- **Тесты:** мок IMAP для юнитов; gated-интеграционный против Яндекс.
- **Не затрагивает:** чтение тел/вложений (отдельный change `mail-attachments`), отправку (Фаза 4), LLM, векторную БД.
- **Новые спеки:** `mail/search` (new capability). Новых моделей/стратегий не вводим.
