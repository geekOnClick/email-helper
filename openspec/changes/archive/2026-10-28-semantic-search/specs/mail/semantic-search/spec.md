# Spec Delta

## ADDED Requirements

### Requirement: Индексация письма в векторное хранилище

Система SHALL предоставлять тул индексации письма, который по логину, UID и (опционально) папке читает письмо через активное почтовое подключение, строит embedding объединённого текста темы и тела и сохраняет письмо с вектором и метаданными в векторное хранилище, перезаписывая при повторной индексации того же письма.

#### Scenario: Индексация нового письма

- **WHEN** тул индексации вызывается с логином и UID письма при активном подключении
- **THEN** система читает письмо, строит embedding текста «тема + тело» и сохраняет узел письма с вектором и метаданными в векторном хранилище

#### Scenario: Повторная индексация обновляет

- **WHEN** тул индексации вызывается для письма, уже индексированного ранее
- **THEN** узел письма обновляется новым вектором и метаданными без создания дубликата

#### Scenario: Требуется активное подключение

- **WHEN** тул индексации вызывается с логином без установленного подключения
- **THEN** система возвращает ошибку с указанием, что требуется предварительно подключиться

### Requirement: Семантический поиск писем

Система SHALL предоставлять тул поиска писем по смыслу, который строит embedding запроса и возвращает top-k ближайших по cosine-сходству писем с их метаданными и оценкой близости.

#### Scenario: Поиск по запросу

- **WHEN** тул поиска вызывается с текстом запроса и числом k
- **THEN** система возвращает до k писем, упорядоченных по убыванию оценки близости

#### Scenario: Фильтрация по аккаунту и папке

- **WHEN** тул поиска вызывается с фильтром по логину и/или папке
- **THEN** система возвращает только письма, удовлетворяющие фильтру

### Requirement: Embedding запроса и письма

Система SHALL строить embeddings через клиент embeddings из единого текста: для письма — объединение темы и тела, для запроса — сам текст запроса.

#### Scenario: Текст письма для embedding

- **WHEN** индексируется письмо с темой и телом
- **THEN** embedding строится из объединённого текста темы и тела письма

#### Scenario: Пустое тело

- **WHEN** индексируется письмо без текстового тела
- **THEN** система использует тему как текст для embedding
