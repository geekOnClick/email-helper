# Spec Delta

## MODIFIED Requirements

### Requirement: Векторный поиск писем

Система SHALL находить top-k ближайших по cosine-сходству писем к переданному вектору запроса и SHALL возвращать для каждого найденного письма его метаданные и оценку близости, опционально фильтруя результаты по логину аккаунта и/или папке.

#### Scenario: Поиск по вектору запроса

- **WHEN** передан вектор запроса и число k
- **THEN** система возвращает до k писем, упорядоченных по убыванию оценки близости

#### Scenario: Фильтрация по свойствам письма

- **WHEN** поиск ограничен условием по свойству узла (напр. логин аккаунта, папка)
- **THEN** система возвращает только письма, удовлетворяющие условию

#### Scenario: Фильтр не указан

- **WHEN** поиск вызван без условий фильтрации
- **THEN** система возвращает письма по всем аккаунтам и папкам
