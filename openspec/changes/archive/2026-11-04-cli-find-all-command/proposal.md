# Proposal

## Why

Команда `/find` возвращает только одно (самое старое) письмо по теме: серверный SEARCH Яндекса по кириллическим
теме-литералам ненадёжен, и тул `mail.search` включает bounded fallback `SINCE now-180д`, после которого локальная
дофильтровка по `subject` оставляет лишь то, что попало в окно. Оператору нужен инструмент, чтобы найти **все** письма
по теме/отправителю (в т.ч. за пределами 180 дней) и оценить объём переписки по датам — без ручного перебора дат в
`/find`.

## What Changes

- Новая guided-команда `/find-all`: поиск писем по теме и/или отправителю с опциональным диапазоном дат «с … по …».
- Если диапазон дат не указан — система ищет по всему ящику (передаёт ранний `since`, чтобы обойти 180-дневный баунд
  fallback тулa `mail.search`).
- Выводит количество найденных писем и список дат писем столбцом (одна дата на строку).
- Если писем больше 10 — выводит первые 10 дат столбцом, а снизу указывает «найдено ещё N писем».
- Команда регистрируется в REPL рядом с `/find`; обновляется справка по slash-командам.
- Реализация переиспользует существующий тул `mail.search` (с его `since`/`before`/`limit`/`offset` и локальной
  дофильтровкой) — новых тулов или изменений `mail/search` не требуется.

## Capabilities

### New Capabilities

_(нет — команда относится к существующей capability `transport/cli`.)_

### Modified Capabilities

- `transport/cli`: добавляется slash-команда `/find-all` с собственным мастером ввода (тема, отправитель, диапазон
  дат «с/по») и форматом вывода (количество + столбец дат с ограничением 10 + «найдено ещё N»); обновляется
  справка команд.

## Impact

- **Код CLI**:
  - `src/transport/cli/commands/find-all.ts` — новый обработчик команды (мастер ввода → `mail.search` с пагинацией
    для полного подсчёта → форматирование дат столбцом).
  - `src/transport/cli/commands/index.ts` — экспорт `runFindAllCommand`.
  - `src/transport/cli/repl.ts` — маршрут `/find-all` → `runFindAllCommand`; deps те же, что у `/find` (`io`,
    `accounts`).
  - `src/transport/cli/prompts.ts` — новый мастер `promptFindAllCriteria` (поля: тема, отправитель, дата с, дата по).
  - `src/transport/cli/format.ts` — `formatDatesList` (столбец дат + «найдено ещё N»).
- **Тул `mail.search`**: без изменений — используется как есть (`since`/`before`/`limit`/`offset`/`total`/
  `hasMore`). Команда сама проходит пагинацию (если `hasMore`) и агрегирует полный список дат.
- **Спека `mail/search`**: без изменений.
- **Зависимости**: новых нет.
- **Тесты**: новые unit-тесты на мастер ввода, форматтер, обработчик команды (с замоканным `mail.search`);
  интеграционный REPL-тест на маршрут `/find-all`.
