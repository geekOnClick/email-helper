# Spec Delta

## ADDED Requirements

### Requirement: Мастер критериев /find-all

Команда `/find-all` SHALL собирать критерии поиска построчно в формате `ключ - значение`: опциональные `тема` (подстрока), `отправитель` (email), `дата с` (ISO `YYYY-MM-DD`, включительно) и `дата по` (ISO `YYYY-MM-DD`, включительно). Система SHALL валидировать формат строки, дату и email; при невалидном вводе SHALL попросить повторить это поле, не прерывая команду. Пустая строка завершает сбор: ≥1 поля → поиск, 0 → отмена. Если указаны обе даты, `дата с` SHALL быть не позже `даты по`.

#### Scenario: Ввод только темы

- **WHEN** пользователь вводит `тема - уроки истории` и завершает пустой строкой
- **THEN** система принимает тему как единственный критерий и ищет по всему ящику

#### Scenario: Ввод темы и диапазона дат

- **WHEN** пользователь вводит `тема - уроки истории`, `дата с - 2024-01-01`, `дата по - 2024-12-31`
- **THEN** система формирует критерии: тема + диапазон дат с 2024-01-01 по 2024-12-31 включительно

#### Scenario: Диапазон дат без темы

- **WHEN** пользователь вводит только `дата с - 2024-06-01` и `дата по - 2024-06-30`
- **THEN** система ищет все письма в диапазоне без фильтра по теме

#### Scenario: Невалидный диапазон — дата с позже даты по

- **WHEN** пользователь ввёл `дата с - 2024-12-31` и `дата по - 2024-01-01`
- **THEN** система выводит сообщение, что `дата с` должна быть не позже `даты по`, и просит повторить ввод

#### Scenario: Невалидная дата

- **WHEN** пользователь вводит `дата с - 2024-13-45`
- **THEN** система выводит, что дата некорректна, и просит повторить ввод этого поля

#### Scenario: Пустой ввод без полей — отмена

- **WHEN** пользователь сразу вводит пустую строку
- **THEN** система отменяет команду без выполнения поиска

#### Scenario: Дубликат поля — повтор ввода

- **WHEN** пользователь вводит `тема - X`, а затем снова `тема - Y`
- **THEN** система сообщает, что поле уже введено, и просит продолжить

### Requirement: Команда /find-all — поиск и вывод таблицей

Команда `/find-all` SHALL искать через тул `mail.search`, передавая на сервер ТОЛЬКО диапазон дат; тема и отправитель SHALL NOT идти на сервер — они фильтруются локально (см. сценарии). Система SHALL вывести таблицу с заголовками «Дата письма | Тема письма | Отправитель» и строками данных. Если диапазон не указан — искать по всему ящику (ранний `since`). Если найдено больше 10 — вывести первые 10 строк и «найдено ещё N». Если 0 — сообщить об отсутствии.

#### Scenario: Найдено 3 письма — таблица с тремя строками

- **WHEN** критериям соответствуют 3 письма с темами/отправителями/датами
- **THEN** система выводит «Найдено писем: 3», заголовки колонок и 3 строки данных (дата, тема, отправитель)

#### Scenario: Найдено 15 писем — 10 строк и остаток

- **WHEN** критериям соответствуют 15 писем
- **THEN** система выводит «Найдено писем: 15», 10 строк данных и строку «найдено ещё 5 писем»

#### Scenario: Диапазон дат не указан — поиск по всему ящику

- **WHEN** пользователь указал только тему и не указал даты
- **THEN** система передаёт в `mail.search` только ранний `since` (без `subject`/`from` на сервере), получает все письма ящика через пагинацию и фильтрует по теме локально — находя письма за весь период, включая письма старше 180 дней

#### Scenario: Ничего не найдено

- **WHEN** критериям не соответствует ни одно письмо
- **THEN** система выводит сообщение об отсутствии результатов

#### Scenario: Полный подсчёт через пагинацию

- **WHEN** `mail.search` возвращает `hasMore: true` для первой страницы
- **THEN** система продолжает запрашивать следующие страницы (увеличивая `offset`), пока `hasMore` не станет false, и агрегирует все письма для вывода

#### Scenario: Тема и отправитель фильтруются локально (case-insensitive)

- **WHEN** пользователь указал тему «уроки» и/или отправителя
- **THEN** система не передаёт `subject`/`from` в серверный `mail.search`, а фильтрует полученные письма локально по подстроке без учёта регистра (с нормализацией пробелов), находя все совпадения, которые серверный SEARCH по теме пропустил бы

### Requirement: Маршрут /find-all в REPL

REPL SHALL маршрутизировать команду `/find-all` на обработчик `find-all` и SHALL включать `/find-all` в справку по slash-командам. Команда SHALL получать тот же набор зависимостей, что и `/find` (ввод/вывод и список аккаунтов из реестра).

#### Scenario: Маршрутизация команды

- **WHEN** пользователь вводит `/find-all`
- **THEN** REPL вызывает обработчик команды `/find-all`

#### Scenario: /find-all в справке команд

- **WHEN** пользователь открывает справку по командам
- **THEN** в списке присутствует `/find-all` с кратким описанием

## MODIFIED Requirements

### Requirement: Slash-команды guided-режима

Система SHALL обрабатывать встроенные slash-команды: `/quit` (завершение сессии), `/stats` (отчёт статистики сессии), `/find` (поиск писем), `/find-all` (поиск всех писем по теме/отправителю и диапазону дат с выводом таблицей: дата, тема, отправитель), `/analyze` (поиск и анализ письма), `/download` (поиск и скачивание вложений), `/send` (отправка письма с подтверждением), `/add-account` (заведение/обновление почтового аккаунта в `.env`). Неизвестная slash-команда SHALL выводить подсказку о доступных командах без выполнения действия.

#### Scenario: Команда завершения

- **WHEN** пользователь вводит `/quit`
- **THEN** система завершает REPL-сессию с освобождением ресурсов

#### Scenario: Команда статистики

- **WHEN** пользователь вводит `/stats`
- **THEN** система выводит текущую сводку сессии (прогоны, вызовы тулов, токены LLM)

#### Scenario: Команда заведения аккаунта

- **WHEN** пользователь вводит `/add-account`
- **THEN** система запускает мастер заведения аккаунта (`provider`, `login`, `password`, `authStrategy`) и сохраняет аккаунт в `.env`

#### Scenario: Команда поиска всех писем

- **WHEN** пользователь вводит `/find-all`
- **THEN** система запускает мастер критериев (тема, отправитель, диапазон дат) и выводит таблицу: количество, дата, тема, отправитель

#### Scenario: Неизвестная команда

- **WHEN** пользователь вводит `/unknown`
- **THEN** система выводит сообщение, что команда неизвестна, и подсказку о доступных командах, не выполняя действия
