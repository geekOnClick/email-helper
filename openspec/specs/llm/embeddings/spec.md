# llm/embeddings Specification

## Purpose

Клиент embeddings RouterAI как источник векторов для векторного хранилища: OpenAI-совместимый запрос embeddings (`POST /embeddings`) для модели `EMBEDDINGS_MODEL`, устойчивость к сетевым сбоям и сокрытие API-ключа.

## Requirements

### Requirement: Запрос embeddings

Система SHALL отправлять OpenAI-совместимый запрос embeddings (`POST /embeddings`) с пакетом входных текстов и моделью из конфигурации и SHALL возвращать массив векторов по одному на каждый входной текст.

#### Scenario: Пакет текстов

- **WHEN** отправляется запрос с несколькими входными текстами
- **THEN** система возвращает массив векторов, длина которого равна числу входных текстов

#### Scenario: Модель из конфигурации

- **WHEN** запрос не указывает модель явно
- **THEN** система использует модель из `EMBEDDINGS_MODEL`

### Requirement: Постоянство размерности векторов

Система SHALL возвращать векторы фиксированной размерности, соответствующей модели embeddings, для всех входных текстов.

#### Scenario: Одинаковая размерность

- **WHEN** запрашиваются embeddings для нескольких текстов разной длины
- **THEN** все возвращённые векторы имеют одинаковую размерность

### Requirement: Повтор при временных сбоях

Система SHALL повторять запрос embeddings при сетевых ошибках и HTTP-ответах 429 и 5xx с экспоненциальной задержкой и SHALL вернуть ошибку, если число попыток исчерпано. Таймаут одного запроса SHALL быть ограничен.

#### Scenario: Повтор на 429

- **WHEN** сервер возвращает 429
- **THEN** система повторяет запрос с задержкой, не более заданного числа попыток

#### Scenario: Повтор на 5xx

- **WHEN** сервер возвращает 500/502/503
- **THEN** система повторяет запрос с экспоненциальной задержкой

#### Scenario: Исчерпание попыток

- **WHEN** все попытки повторов исчерпаны безуспешно
- **THEN** система возвращает ошибку с указанием статуса, не раскрывая секрет

#### Scenario: Таймаут запроса

- **WHEN** ответ сервера не получен в течение заданного таймаута
- **THEN** система прерывает запрос и либо повторяет, либо возвращает ошибку таймаута

### Requirement: Обработка некорректного ответа

Система SHALL валидировать структуру ответа embeddings API и SHALL возвращать понятную ошибку при malformed-ответе (отсутствие `data`, повреждённый JSON), не выбрасывая необработанное исключение наружу.

#### Scenario: Malformed JSON

- **WHEN** тело ответа не является валидным JSON
- **THEN** система возвращает ошибку парсинга ответа

#### Scenario: Нет данных embeddings

- **WHEN** ответ не содержит `data` или `data[0].embedding`
- **THEN** система возвращает ошибку о неожиданной структуре ответа

### Requirement: Сокрытие API-ключа

Система SHALL NOT включать `ROUTERAI_API_KEY` (или его часть) в сообщения об ошибках embeddings.

#### Scenario: Ошибка без раскрытия ключа

- **WHEN** запрос embeddings завершается ошибкой аутентификации (401) или сети
- **THEN** сообщение об ошибке не содержит значения API-ключа
