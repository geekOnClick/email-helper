# Как пользоваться веб-версией

Краткое руководство для нового пользователя: как запустить веб-интерфейс
email-helper и начать работать с почтой.

---

## Что нужно заранее

1. **Node.js ≥ 20** — проверить: `node --version`. Если Node.js на ПК нет, но можно установить с сайта https://nodejs.org/en/download либо с ваших корпоративных ресурсов

! ОБРАТИТЕ ВНИМАНИЕ !
Для корректной работы агента с вашим почтовым ящиком при добавлении нужно указать НЕ ВАШ ЛИЧНЫЙ ПАРОЛЬ ДЛЯ ВХОДА, А ПАРОЛЬ ПРИЛОЖЕНИЯ. Для задания данного пароля, необходимо перейти в настройки вашего почтового ящика в раздел Безопасность и найти там настройку, связанную с Паролями приложений для IMAP,POP3,SMTP. После этого, почтовый клиент предложит вам ввести имя пароля (любое) и выдаст пароль, который вы сможете вставить при добавлении аккаунта.
Некоторые почтовые клиенты требуют дополнительного разрешения для работы внешних приложений с почтовым ящиком. Эту настройку как правило также можно найти в разделе Безопасность.

! Для Mac OS для запуска агента необходимо запустить start-web-dev-mac.command !

! Для корректной работы Outlook через агента требуется получить Oauth token. Для этого после запуска агента и начала выполнения любой команды (например Smart Send) вернитесь в терминал и перейдите по ссылке. Выполните авторизационные действия для получения токена. После этого, вы можете продолжить пользоваться агентом.

---
## Шаг 1. Откройте файл .env и заполните поля согласно инструкциям. После этого, переименуйте файл, удалив ".example", должно остаться .env

Фактически требуется только зарегистрироваться в любом LLM провайдере, найти на сайте API и вставить его в поле ROUTERAI_API_KEY

## Шаг 2. Установка зависимостей (один раз)

В терминале выполните команду: 
```bash
npm install
```
Удостоверьтесь, что команда была успешно завершена.
---

## Шаг 3. Запуск

Откройте файл **`start-web-dev.sh`** или  **`sstart-web-dev-mac.command`** на маке двойным кликом в файловом менеджере (Либо правой кнопкой мыши - "Открыть как приложение")

- Сам найдёт Node.js и npm.
- Если `node_modules` нет — установит зависимости.
- Если сборка фронтенда устарела — пересоберёт.
- Поднимет сервер и **откроет браузер** автоматически.


## Шаг 4. Работа в интерфейсе

1. **Выберите аккаунт** в выпадающем списке сверху (из `ACCOUNTS`).
   Нет нужного — нажмите «+ добавить аккаунт» и заполните форму.
2. **Найдите письма:**
   - **Умный поиск** — опишите запрос обычными словами («письма от Иванова за прошлую неделю с вложениями»), LLM сам разберёт критерии.
   - **Обычный поиск** — заполните поля формы (тема, отправитель, дата и т.п.).
3. **Читайте письма** — кликните письмо в списке слева, тело откроется справа.
4. **Проанализируйте письмо** — кнопка «Анализировать»: саммари, сущности, темы.
   Можно массово: «Анализировать много» (по выбранным письмам) или
   «Анализ вложений» (по вложениям писем).
5. **Отправьте письмо** — кнопка «Отправить»: заполните получателей, тему, тело,
   нажмите «Сгенерировать» для предпросмотра черновика, проверьте, затем
   «Отправить».

## Остановка сервера

В терминале, где запущен сервер — **`Ctrl+C`**.

---

## Если что-то не работает

- **Не открывается страница** — проверьте, что порт из `WEB_PORT` свободен и
  совпадает с тем, что в адресной строке.
- **«подключение не установлено»** — сначала выберите аккаунт и папку, чтобы
  создать IMAP-сессию.
- **Ошибка авторизации почты** — проверьте `provider`, `login`, `password` в
  `ACCOUNTS` (для Яндекса нужен пароль приложения, не основной).
- **Новый аккаунт не виден** — он сохраняется в `.env`; перезапустите сервер
  (он читает `.env` при старте).
